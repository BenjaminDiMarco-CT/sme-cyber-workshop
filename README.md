# SME cyber workshop pack

Phone-friendly workshop pack for the CyberCon 2026 session *Designing and implementing an effective cyber insurance program for SMEs*.

Live at https://benjamindimarco-ct.github.io/sme-cyber-workshop/

The pack contains a fictional example business, a short-form cyber proposal form to work through, and links to public resources. Answers entered on the page stay in the viewer's browser and are not sent anywhere. General information only, not legal or insurance advice.
